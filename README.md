# موقع آدم إسماعيل — مدرب سباحة

موقع شخصي احترافي ثنائي اللغة (عربي/إنجليزي) لمدرب السباحة آدم إسماعيل محمد علي، مبني بـ HTML + CSS + JavaScript فقط (بدون أي Backend)، وجاهز للنشر مباشرة على **GitHub Pages**.

## 📁 هيكل المشروع

كل الصور والفيديوهات وملف الـ PDF موجودة **في المجلد الرئيسي مباشرة** (بدون أي مجلد فرعي)، بينما CSS و JS في مجلديهما الخاصين:

```
├── index.html              الصفحة الرئيسية
├── about.html               المعلومات الأساسية
├── courses.html              الدورات التدريبية والمؤهلات
├── experience.html          الخبرات السابقة (Timeline)
├── cv.html                  السيرة الذاتية
├── gallery.html              معرض صور السباحين
├── certificates.html         الشهادات
├── videos.html               الفيديوهات
├── css/
│   └── style.css            كل تنسيقات الموقع
├── js/
│   ├── translations.js      كل نصوص وبيانات الموقع (عدّل هنا لإضافة/تعديل أي محتوى)
│   └── main.js               منطق الموقع: الهيدر، الفوتر، تبديل اللغة، القوائم، الـ Lightbox
├── adam-profile.jpg          الصورة الشخصية
├── hero-swimmer-action.jpg   صورة الهيدر الرئيسية
├── hero-coach-swimmer.jpg    صورة قسم رؤية المدرب
├── gallery-01.jpg … gallery-12.jpg      صور السباحين (12 صورة)
├── cert-01-bachelor.jpg … cert-12-armed-forces.jpg   صور الشهادات (12 شهادة)
├── video-01.mp4 … video-06.mp4          الفيديوهات (6 فيديوهات)
├── video-01-thumb.jpg … video-06-thumb.jpg  الصور المصغّرة للفيديوهات
└── CV-Adam-Ismail.pdf        ملف السيرة الذاتية
```

## 🚀 كيفية النشر على GitHub Pages

1. أنشئ مستودع (Repository) جديد على GitHub.
2. ارفع كل محتويات هذا المجلد إلى المستودع (بنفس الهيكل، دون تعديل أسماء المجلدات).
3. من إعدادات المستودع (Settings) → Pages → اختر الفرع (Branch) `main` والمجلد `/root`.
4. بعد دقيقة أو دقيقتين سيكون الموقع متاحًا على رابط مثل:
   `https://username.github.io/repository-name/`

لا حاجة لأي إعداد إضافي أو تثبيت حزم — الموقع يعمل مباشرة كملفات ثابتة (Static Files).

## ✏️ كيفية تعديل المحتوى مستقبلًا

كل النصوص والبيانات (العناوين، الأزرار، الدورات، الخبرات، الشهادات، الفيديوهات، بيانات التواصل...) موجودة في **ملف واحد فقط**:

```
js/translations.js
```

كل نص له نسخة عربية (`ar`) ونسخة إنجليزية (`en`) بجانب بعضها — عدّل القيمة المطلوبة في اللغتين للحفاظ على التطابق.

### مثال: إضافة دورة تدريبية جديدة
ابحث عن `courses:` في `translations.js` وأضف عنصرًا جديدًا في كل من مصفوفة `ar` و `en`:
```js
{ title: "اسم الدورة", issuer: "الجهة المانحة", date: "2026", desc: "وصف مختصر", image: "cert-13-new.jpg" }
```

### مثال: إضافة صورة جديدة للمعرض
1. ضع الصورة في المجلد الرئيسي (بجانب index.html مباشرة).
2. أضف عنصرًا جديدًا في `gallery:` (بنفس الطريقة أعلاه) في كل من `ar` و `en` بالاسم فقط، مثل: `"image": "gallery-13.jpg"`.

### مثال: إضافة فيديو جديد
1. ضع الفيديو في المجلد الرئيسي (ويفضّل أن يكون مضغوطًا لحجم أقل).
2. أضف عنصرًا جديدًا في `videos:` مع اسم ملف الفيديو وصورة مصغّرة (thumbnail)، مثل: `"src": "video-07.mp4"`.

## 🎨 التصميم
- الألوان: أزرق داكن (Navy) + أزرق مائي (Aqua/Cyan) + أبيض، مستوحاة من عالم السباحة.
- الخطوط: Cairo / Tajawal للعربية، Poppins / Inter للإنجليزية (عبر Google Fonts — يتطلب اتصال إنترنت عند فتح الموقع).
- الموقع متجاوب بالكامل (Responsive) مع الموبايل والتابلت والكمبيوتر.
- دعم كامل لاتجاه RTL عند العربية و LTR عند الإنجليزية — بما في ذلك أرقام الهاتف التي تُعرض بالاتجاه الصحيح دائمًا.

## ⚠️ ملاحظات
- رقم الواتساب والفيسبوك مُفعّلان بالفعل. إذا رغبت في إضافة إنستغرام أو يوتيوب لاحقًا، أضف الروابط في `contact.ar.instagramUrl` و `contact.ar.youtubeUrl` (وكذلك `en`) داخل `translations.js`، وسيظهران تلقائيًا في قسم التواصل.
- لتغيير رقم الهاتف/الواتساب/الإيميل: عدّل القيم داخل `contact:` في `translations.js` فقط — ستتحدث في كل الصفحات تلقائيًا (الهيدر، الفوتر، صفحة التواصل).
